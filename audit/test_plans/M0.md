## Interface the tests call (`src/m0_qc.py`)

Naming/interface only; no result-changing choices. Invalid input raises `ValueError` with a message naming the violated assumption.

```python
load_inputs(h5ad_path, geo_path, expected_sha256=None) -> tuple[AnnData, pd.DataFrame]
    # Validates: X non-negative integers; GEO columns tsne1 tsne2 ind stim cluster cell multiplets.

join_author_metadata(adata, geo) -> AnnData
    # h5ad obs uses: index = barcode ("SEQ-1" ctrl / "SEQ-2" stim), label ("ctrl"/"stim"),
    #   replicate ("patient_<id>"), cluster, tsne1, tsne2.
    # GEO: index = barcode ("SEQ-1", or "SEQ-11" for stim collisions), stim, ind, cluster, cell, tsne1, tsne2, multiplets.
    # Key: (barcode without "-<digits>" suffix, condition).
    # Returns same cells, same order; obs gains: barcode, condition, donor (= replicate), cell_type (= GEO cell).
    # Raises if any cell unmatched, any key duplicated, or donor/cluster/t-SNE disagree.

compute_qc_metrics(adata) -> AnnData      # obs: n_counts, n_genes, pct_ribo (RPL*/RPS* genes, %); var: n_cells
basic_filter(adata, min_genes=200, min_cells=3) -> AnnData   # cells first, then genes, counted across all cells
mad_outlier(values, n_mads=5.0) -> np.ndarray[bool]   # |v - median| > n_mads * raw MAD, within one group (T6 boundary cases)
flag_qc(adata, n_mads=5.0, min_cells_group=10, min_paired_donors=3) -> AnnData
    # Adds boolean obs: flag_outlier (> n_mads raw MADs on log1p n_counts or log1p n_genes, per donor × condition),
    #   flag_small_group (donor × condition × cell_type group < min_cells_group),
    #   flag_underpowered_celltype (cell type with < min_paired_donors donors having both conditions).
    # Never removes cells.
validate_assumptions(adata) -> None        # 8 donors × both conditions; unique var_names; exactly 8 cell types
run_m0(h5ad_path, geo_path, out_dir, expected_sha256=None) -> list[dict]
    # Runs all steps; validates before writing anything; writes out_dir/m0_cells.h5ad and out_dir/cell_flow.md.
    # Returns flow records: {step, n_cells_in, n_cells_out, n_genes_in, n_genes_out, n_matched (join only)}.
```

Real-data constants: sha256 `e6a5adac64dcdeb36eaba27db49b63e0c64bb0ed4a64c6705971506b41c39830`; cell types `B cells`, `CD14+ Monocytes`, `CD4 T cells`, `CD8 T cells`, `Dendritic cells`, `FCGR3A+ Monocytes`, `Megakaryocytes`, `NK cells`. Real-data tests are marked `@pytest.mark.realdata`.
