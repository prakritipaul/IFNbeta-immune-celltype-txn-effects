## Interface the tests call

Naming/interface only; no result-changing choices. Invalid input raises `ValueError` naming the violated assumption, before any file is written.

```python
# src/m3_signature.py
IFNA = "HALLMARK_INTERFERON_ALPHA_RESPONSE"; IFNG = "HALLMARK_INTERFERON_GAMMA_RESPONSE"
MSIGDB_GMT = "data/msigdb/h.all.v2026.1.Hs.symbols.gmt"; MSIGDB_SHA256 = "eecaf6dad908334ae885406ec72bdc0646d8917588ed7c219fac92fc5363f596"
GENE_MAPPING = {"TENT5A": "FAM46A", "WARS1": "WARS", "MARCHF1": "MARCH1", "RIGI": "DDX58", "TMT1B": "METTL7B", "PSMA2": "PSMA2.1"}

load_gene_sets(gmt_path, expected_sha256, names=(IFNA, IFNG)) -> dict[str, list[str]]
    # Raises on sha256 mismatch or a missing set.

    # Applies mapping; returns mapped sets + coverage table (set, n_genes, n_found, pct_found).
    # Raises naming any gene still absent from var_names.
score_cells(adata, gene_sets, target_sum=1e4, ctrl_size=50, n_bins=25, random_state=0) -> pd.DataFrame
    # adata: raw counts (not modified). gene_sets: {IFNA: [...], IFNG: [...]} already mapped.
    # Returns one row per cell (index = obs_names): ifna_score, ifng_score, ifng_noshared_score
    #   (IFNG minus genes also in IFNA). Raises if any score is NaN.
summarise_samples(cell_scores, obs, min_cells=10) -> pd.DataFrame
    # One row per kept donor × cell type × condition (A1, missing condition = 0 cells):
    #   cell_type, donor, condition, n_cells, and the mean of each score.
paired_differences(sample_scores, control="ctrl", treatment="stim") -> pd.DataFrame
    # One row per donor × cell type: stim − ctrl for each score.
run_m3(in_path, gmt_path, out_dir, expected_sha256=MSIGDB_SHA256, **params) -> None
    # Writes m3_cell_scores.csv, m3_sample_scores.csv (and m3_gene_sets.md to audit_dir if given). Nothing on failure.
```
